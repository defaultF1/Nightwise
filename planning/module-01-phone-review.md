# Module 1 phone review

This is a checklist for a future physical Android check, not a record of tests already performed. Module 1 browser checks have passed. Consult nightwise-current-status.md for APK availability.

## App shell checks

1. Install the explicitly labelled debug APK on the intended tutorial phone. Record the phone model, Android version, APK hash and test date.
2. On a fresh installation, verify the blue/navy and teal default, NightWise branding, readable system bars and the bundled launch. Check that Skip works and that the journey form appears promptly.
3. Open Settings, choose Mono Light, close and reopen the app. Confirm that the appearance remains selected. Repeat for Mono Dark, then restore blue for the shoot.
4. Open a sheet and use Android Back. Confirm that the sheet closes first. Check return from the tutorial preview and the home-screen Back behavior.
5. Check the smallest expected screen, a larger system font, keyboard focus where available, and touch targets. Confirm that content is not obscured by status/navigation bars.
6. With reduced-motion settings enabled, confirm direct access to the app. With the phone offline, confirm the bundled shell and appearance changes still work. Do not expect live maps or current conditions.
7. Tap Use my location in this module. It should explain the tutorial's prepared origins without requesting OS location access. Select either Manyata Tech Park or Sahakar Nagar and confirm the chosen name remains on the form.

## Record findings

Record pass/fail, reproduction steps, expected versus actual behavior and screenshots for failures. Do not record personal notifications or credentials in screenshots. Report actual device results in a later module handoff rather than backdating them into the current browser record.

## Boundaries

Sample times, distances, counts and map placeholders are fictional. Live routes, current activity, native map interaction, location services and the actual Google Maps corridor require later integration and local rehearsal. No API key is needed to review this shell.
